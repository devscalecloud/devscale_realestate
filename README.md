# devscale_realestate

DevScale Real Estate — a demo property portal built in Go.

Users log in (or register), browse properties for sale and for rent, buy or rent
a property through a mock card-payment modal, and see a success confirmation.
No real payments are processed — this is a demo application.

## Run

```
go run .
```

Then open http://localhost:8080

Demo login: username `dapo`, password `welcome+1` (see the login page for the full list).
